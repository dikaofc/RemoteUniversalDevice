## ⚡ Overview

**RemoteUniversalDevice** adalah sistem kendali jarak jauh (Remote Access & Command Controller) *cross-platform* yang dirancang untuk menjembatani komunikasi data real-time antara **PC**, **Android**, dan perangkat **IoT/Microcontroller**. 

Mendukung eksekusi perintah tingkat rendah (low-level shell commands), monitoring performa perangkat secara langsung, serta kontrol perangkat terintegrasi melalui protokol terenskripsi berkecepatan tinggi.
